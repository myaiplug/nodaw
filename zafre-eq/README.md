# NoDAW ZAFRE EQ

High-fidelity HTML/CSS/Canvas visual prototype inspired by premium hardware parametric EQ interfaces.

## Demo

Open `index.html` directly or deploy the repository/subdirectory as a static site.

## Current features

- Animated spectrum visualizer
- Multiple EQ response curves
- Dual dB scales and frequency scale
- Animated spectrum bars
- Interactive vertically draggable controls
- Four-band gain controls
- Q controls
- Frequency controls
- Trim / preamp / output / alive controls
- Hardware-inspired metal chassis and calibration markings
- No external runtime dependencies

This is currently a visual prototype; it does not yet perform audio DSP.
